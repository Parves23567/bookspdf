# আমার বাংলা লাইব্রেরি (Bangla Digital Library & PDF Reading App)

একটি আধুনিক, দ্রুতগতির, সুন্দর এবং সম্পূর্ণ **Mobile-Friendly** বাংলা PDF রিডার ও প্রগ্রেসিভ ওয়েব অ্যাপ (PWA)। এই অ্যাপটির মাধ্যমে মোবাইল ও কম্পিউটার উভয় ডিভাইস থেকে সহজে এবং আরামদায়কভাবে বাংলা PDF বই পড়া যায়।

---

## 🌟 সম্পন্নকৃত ফিচারসমূহ (Completed Features)

### ১. মূল ড্যাশবোর্ড (Main Dashboard)
- **হিরো সেকশন:** "আমার বাংলা লাইব্রেরি" এবং সাবটাইটেল "আপনার পছন্দের বই, আপনার হাতেই"।
- **লাইব্রেরি গ্রিড:** প্রতিটি বইয়ের সুন্দর ৩ডি কার্ড, প্রচ্ছদ (Cover), লেখক, মোট পৃষ্ঠা সংখ্যা ও বিষয়ভিত্তিক ক্যাটাগরি।
- **পড়ার অগ্রগতি ট্র্যাকিং:** সর্বশেষ কত পৃষ্ঠা পড়া হয়েছে তা স্বয়ংক্রিয়ভাবে সেভ হয় এবং পার্সেন্টেজ (%) প্রগ্রেস বার দেখায়।
- **পড়া চালিয়ে যান (Continue Reading):** সর্বশেষ যে বইটি পড়া হচ্ছিল তা ড্যাশবোর্ডের উপরে হাইলাইট হয় এবং এক ক্লিকেই আগের পৃষ্ঠা থেকে পড়া শুরু করা যায়।
- **ক্যাটাগরি ফিল্টার:** বিষয়ভিত্তিক বই ফিল্টারিং।

### ২. PDF Reading Interface (মূল PDF ভিউয়ার)
- **PDF.js ইঞ্জিন:** ক্যানভাস ভিত্তিক ক্রিস্প ও শার্প বাংলা ও আরবি রেন্ডারিং।
- **রেসপনসিভ অটো-ফিট:** মোবাইলের পর্দার প্রস্থ অনুযায়ী পৃষ্ঠা স্বয়ংক্রিয়ভাবে Fit Width হয়।
- **কন্ট্রোলস ও জুম:** Zoom In, Zoom Out, Fit Width এবং মোবাইল ডিভাইসে **Pinch-to-Zoom** ও **Horizontal Swipe** দিয়ে পৃষ্ঠা পরিবর্তন।
- **পৃষ্ঠা নেভিগেশন:** আগের পৃষ্ঠা, পরের পৃষ্ঠা এবং সরাসরি পৃষ্ঠার নম্বর লিখে জাম্প করার সুবিধা।
- **ফুলস্ক্রিন মোড:** ডেক্সটপ ও মোবাইলে সম্পূর্ণ ফুলস্ক্রিনে পড়ার সুবিধা।
- **রিডিং প্রগ্রেস বার:** স্ক্রিনের উপরে সূক্ষ্ম প্রগ্রেস বার।
- **ডিজট্র্যাকশন-ফ্রি ইন্টারফেস:** মোবাইল স্ক্রিনে ক্যানভাসে ট্যাপ করলে টুলবার স্বয়ংক্রিয়ভাবে লুকানো ও দেখানো যায়।

### ৩. Mobile Reading Mode (টেক্সট রিডিং মোড)
- PDF-এর মূল পৃষ্ঠার পাশাপাশি এটি একটি বিকল্প পাঠ্য মোড।
- PDF.js Text Layer ব্যবহার করে বাংলা লেখা সুন্দর ফরম্যাটে প্যারাগ্রাফ আকারে সাজিয়ে উপস্থাপন করে।
- **টাইপোগ্রাফি কন্ট্রোল:**
  - ফন্ট সাইজ ছোট-বড় করার সুবিধা (A- / A+)।
  - লাইন স্পেসিং ও প্যারাগ্রাফ বিন্যাস।
  - বাংলা ফন্ট সুইচ (Hind Siliguri ও Noto Serif Bengali)।
- মূল PDF-এর পৃষ্ঠা নম্বরের সাথে টেক্সট মোডের পৃষ্ঠা পুরোপুরি সিঙ্ক থাকে।

### ৪. সূচিপত্র (Table of Contents)
- তিনটি বইয়েরই PDF-এ থাকা মূল সূচিপত্র ও অধ্যায়সমূহ হুবহু সাজানো রয়েছে।
- প্রতিটি অধ্যায়ের নামের ওপর ক্লিক করলে সরাসরি সংশ্লিষ্ট পৃষ্ঠায় নিয়ে যায়।
- সূচিপত্রের ভেতর অধ্যায় খোঁজার সার্চ সুবিধা।
- প্রয়োজনে ম্যানুয়ালি নতুন অধ্যায় যোগ করার সুবিধা।

### ৫. দ্রুতগতির সার্চ সিস্টেম (Search System)
- **গ্লোবাল সার্চ:** পুরো লাইব্রেরির বইয়ের নাম, লেখক এবং বইয়ের ভেতরের সব লেখার মধ্যে সার্চ।
- **বইয়ের ভেতরের সার্চ:** বইয়ের ভেতরের নির্দিষ্ট বাংলা শব্দ সার্চ করলে কোন কোন পৃষ্ঠায় শব্দটি কতবার আছে এবং তার আশপাশের লেখার স্নsnippet সহ দেখায়।
- **প্রি-বিল্ট ইনডেক্স (`search-index.json`):** ব্রাউজার হ্যাং না করে মাত্র কয়েক মিলিসেকেন্ডে সার্চ রেজাল্ট প্রদর্শন করে।

### ৬. বুকমার্ক ও লোকাল স্টোরেজ (Bookmarks & LocalStorage)
- যেকোনো পৃষ্ঠায় থাকা অবস্থায় Bookmark করা যায়।
- বুকমার্ক ড্রয়ারে তারিখ ও টেক্সট সহ বুকমার্কের তালিকা দেখা যায়।
- এক ক্লিকে বুকমার্ক করা পৃষ্ঠায় জাম্প করা যায়।
- পেজ পরিবর্তন করলে ব্রাউজারের `localStorage`-এ স্বয়ংক্রিয়ভাবে সেভ থাকে।

### ৭. PWA ও সম্পূর্ণ অফলাইন সাপোর্ট (Offline PWA)
- Android Chrome ও iOS Safari থেকে **Home Screen-এ Install** করা যায়।
- কাস্টম অ্যাপ আইকন (১৯২x১৯২, ৫১২x৫১২ ও SVG)।
- `sw.js` (Service Worker) অ্যাপ শেল, ফন্ট ও পড়া বইসমূহ ক্যাশ করে রাখে, ফলে **ইন্টারনেট সংযোগ ছাড়াও বই পড়া যায়**।
- অনলাইন/অফলাইন রিয়েল-টাইম স্ট্যাটাস নির্দেশক ব্যাজ।
- প্রিমিয়াম ডিজিটাল লাইব্রেরি কালার প্যালেট (Emerald Green `#0f3a2f` ও Gold `#d4af37`)।
- লাইট, সেপিয়া (Sepia/বইয়ের পাতা) এবং ডার্ক নাইট মোড ফিল্টার।

## 💻 লোকাল কম্পিউটারে কীভাবে চালাবেন (How to Run Locally)

আপনার কম্পিউটারে Node.js ইনস্টল করা থাকলে:

১. টার্মিনাল বা PowerShell খুলে প্রজেক্ট ফোল্ডারে প্রবেশ করুন:
```bash
cd "c:\Users\BPA\Pictures\GOOGLE ANTIGRAVITY\বুক আপ্স"
```

২. প্যাকেজ ইনস্টল করুন (যদি ইতিমধ্যে না করা থাকে):
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
টার্মিনালে একটি লিংক দেখতে পাবেন (যেমন `http://localhost:3000` বা `http://localhost:5173`)। ব্রাউজারে লিংকটি খুললে অ্যাপটি চালু হবে।

৪. প্রোডাকশন বিল্ড তৈরি ও প্রিভিউ দেখতে চাইলে:
```bash
npm run build
npm run preview
```

## 🚀 Vercel-এ কীভাবে ডিপ্লয় করবেন (How to Deploy to Vercel)

অ্যাপটি Vercel-এর জন্য সম্পূর্ণ প্রস্তুত। ডিপ্লয় করার দুটি সহজ উপায় রয়েছে:

### পদ্ধতি ১: GitHub ও Vercel ওয়েবসাইটের মাধ্যমে (সবচেয়ে সহজ)
১. কোডগুলো একটি নতুন GitHub রিপোজিটরিতে Push করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Bangla Digital Library"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
২. [vercel.com](https://vercel.com)-এ লগইন করে **"Add New Project"**-এ ক্লিক করুন।
৩. আপনার GitHub রিপোজিটরিটি সিলেক্ট করুন।
৪. Framework Preset হিসেবে **Vite** সিলেক্ট থাকবে এবং Build Command হবে `npm run build` ও Output Directory হবে `dist`।
৫. **Deploy** বাটনে ক্লিক করলেই ১-২ মিনিটের মধ্যে লাইভ লিংক পেয়ে যাবেন।

### পদ্ধতি ২: Vercel CLI দিয়ে সরাসরি টার্মিনাল থেকে
```bash
npx vercel
```
টার্মিনালের নির্দেশাবলী অনুসরণ করলেই সরাসরি ডিপ্লয় হয়ে যাবে।

## ➕ নতুন PDF বই কীভাবে যুক্ত করবেন (How to Add New Books)

প্রজেক্টের আর্কিটেকচার এমনভাবে ডিজাইন করা হয়েছে যাতে মূল অ্যাপের কোড পরিবর্তন না করেই নতুন বই যোগ করা যায়:

১. নতুন PDF ফাইলটি `public/books/` ফোল্ডারে রাখুন (যেমন `amar-notun-boi.pdf`)।
২. বইটির প্রচ্ছদ ছবি `public/covers/` ফোল্ডারে রাখুন (যেমন `amar-notun-boi.png`)।
৩. `src/config/booksConfig.js` (অথবা `public/data/books.json`) ফাইলে একটি নতুন এন্ট্রি যোগ করুন:

## ☁️ ভবিষ্যতে Firebase যুক্ত করার নির্দেশনা (Firebase Integration Guide)

বর্তমানে অ্যাপটি ব্রাউজারের `localStorage`-এ নির্ভুলভাবে পড়া কতদূর হলো এবং বুকমার্ক সংরক্ষণ করে। পরবর্তীতে কোনো অ্যাকাউন্টের সাথে গুগল সাইন-ইন বা একাধিক ডিভাইসের মধ্যে সিঙ্ক করার জন্য Firebase যুক্ত করতে চাইলে:

১. ফায়ারবেস প্যাকেজ ইনস্টল করুন:
```bash
npm install firebase
```
২. `src/services/` ফোল্ডারে `firebase.js` তৈরি করে আপনার Firebase কনফিগ বসান:
```javascript
import { initializeApp } from "firebase/app";
import { getFirestore } from "firebase/firestore";
import { getAuth } from "firebase/auth";

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  // ...
};

const app = initializeApp(firebaseConfig);
export const db = getFirestore(app);
export const auth = getAuth(app);
```
৩. `src/services/storageService.js` ফাইলে দেখুন ইতিমধ্যে `this.cloudSyncEnabled` এবং `syncProgressToCloud()`, `syncBookmarksToCloud()` মেথড তৈরি করা আছে। সেখানে `this.cloudSyncEnabled = true` করে দিলেই ফায়ারবেসে ক্লাউড সিঙ্ক চালু হয়ে যাবে। কোনো UI কম্পোনেন্টে হাত দিতে হবে না।
